# 音效文件说明

将以下三个文件放到本目录，然后重新运行 `install.sh`：

| 文件名 | 用途 | 去哪找 |
|--------|------|--------|
| `ribbit.wav` | 青蛙叫声（等待确认） | [freesound.org](https://freesound.org) 搜 `frog ribbit single`，筛选 CC0 授权 |
| `ding.wav` | 微波炉叮声（任务完成） | [freesound.org](https://freesound.org) 搜 `microwave ding`，筛选 CC0 授权 |
| `meow.wav` | 猫叫声（报错） | [freesound.org](https://freesound.org) 搜 `cat meow single`，筛选 CC0 授权 |

## 没有音效文件也没关系

macOS 用户不放音效文件，自动使用系统内置声音：
- 青蛙叫 → Pop.aiff
- 任务完成 → Glass.aiff
- 报错 → Purr.aiff

系统通知（右上角弹窗）在任何情况下都会正常工作。
